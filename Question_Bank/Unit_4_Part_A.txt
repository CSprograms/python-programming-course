=== Q2
Question: How do you add values to a list in python?
KL: K2
CO: CO4
PO: PO2,PO3
PSO: PSO1
Asked: November 2025 Q7
Answer:
Values can be added to a list in these ways:
1. append(x): adds one item at the end.
2. insert(i, x): adds an item at index i.
3. extend(iterable): adds all items of another list (or sequence) at the end.
4. + operator: joins two lists into a new list.

```python
nums = [10, 20]
nums.append(30)
nums.insert(0, 5)
nums.extend([40, 50])
nums = nums + [60]
print(nums)
```

Output:
```text
[5, 10, 20, 30, 40, 50, 60]
```

=== Q4
Question: What is immutable string?
KL: K1
CO: CO4
PO: PO1
PSO: PSO1
Asked: November 2023 Q5
Answer:
In Python, strings are immutable: once a string is created, its characters cannot be changed. Assigning to an index such as s[0] = 'J' gives a TypeError. To "change" a string, a new string is created, for example with slicing, + or replace().

```python
s = "Python"
try:
    s[0] = "J"
except TypeError as e:
    print("Error:", e)
s = "J" + s[1:]          # new string created
print(s)
```

Output:
```text
Error: 'str' object does not support item assignment
Jython
```

=== Q6

KL: K1
CO: CO4
PO: PO1
PSO: PSO1
Asked: April 2025 Q5
Answer:
String functions (methods) are built-in functions used to work on strings, such as changing case, searching, replacing and splitting. Because strings are immutable, they return a new string or value; the original string is not changed.

Common string functions: len(), upper(), lower(), title(), capitalize(), strip(), find(), replace(), split(), join(), count(), startswith(), isdigit().

```python
s = "  hello python  "
print(len(s), s.strip().upper(), s.count("o"), s.strip().replace("python", "world"))
```

Output:
```text
16 HELLO PYTHON 2 hello world
```

=== Q7
Question: Write a string compare function in python.
KL: K3
CO: CO4
PO: PO2,PO3,PO5
PSO: PSO1
Asked: November 2024 Q6
Answer:
Strings are compared with the relational operators ==, !=, <, >, <=, >=. The comparison is character by character using Unicode (ASCII) values, so it is case-sensitive ("A" < "a"). For a case-insensitive comparison, convert both strings with lower().

```python
def compare(s1, s2):
    if s1 == s2:
        return "Both strings are equal"
    elif s1 < s2:
        return s1 + " comes before " + s2
    else:
        return s1 + " comes after " + s2

print(compare("apple", "apple"))
print(compare("apple", "banana"))
print(compare("Zoo", "ant"))
print("Python".lower() == "PYTHON".lower())
```

Output:
```text
Both strings are equal
apple comes before banana
Zoo comes before ant
True
```

Question: Write down the purpose of append function.
KL: K2
CO: CO4
PO: PO1,PO2
PSO: PSO1
Asked: November 2024 Q10
Answer:
append() is a list method that adds a single item to the end of a list. It changes the original list and returns None. If a list is appended, it is added as one nested item.

Syntax:  list_name.append(item)

```python
names = ["Anu", "Bala"]
names.append("Charu")
names.append([1, 2])
print(names, len(names))
```

Output:
```text
['Anu', 'Bala', 'Charu', [1, 2]] 4
```
