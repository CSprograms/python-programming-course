Question: How to declare and initialize variable?
KL: K2
CO: CO1
PO: PO1,PO2
PSO: PSO1
Asked: November 2023 Q11
Answer:
In Python a variable is declared and initialized in one step: write the variable name, the assignment operator = and a value. No data type is written; Python decides the type from the value.

Syntax:  variable_name = value

```python
age = 19              # int
name = "Priya"        # str
a, b, c = 1, 2, 3     # several variables in one line
x = y = 0             # same value to many variables
print(age, name, a, b, c, x, y)
```

Output:
```text
19 Priya 1 2 3 0 0
```

=== Q2
Question: List out the rules to declare a variable in python.
KL: K1
CO: CO1
PO: PO1
PSO: PSO1
Asked: November 2024 Q1
Answer:
Rules for naming a variable (identifier) in Python:
1. The name can contain letters (a–z, A–Z), digits (0–9) and the underscore ( _ ).
2. It must start with a letter or an underscore, not a digit (1total is invalid).
3. Spaces and special symbols such as @, $, %, - are not allowed (my-name is invalid).
4. A keyword cannot be used as a name (for, if, class are invalid).
5. Names are case-sensitive: total, Total and TOTAL are three different variables.

Valid: total, _count, mark1, student_name        Invalid: 1mark, my name, for, a$b

Question: What is Comment?
KL: K1
CO: CO1
PO: PO1
PSO: PSO1
Asked: April 2025 Q2
Answer:
A comment is a note written in the program to explain the code. The Python interpreter ignores comments; they are not executed.

- Single-line comment: starts with the # symbol.
- Multi-line comment: several lines each starting with #. A string in triple quotes (""" ... """) that is not assigned to a variable is also often used as a multi-line comment.

```python
# This program adds two numbers
a = 10
b = 20
print(a + b)   # prints the sum
```

Answer:
A comment is an explanatory note in a program that is ignored by the Python interpreter. It makes the program easier to read and understand. A single-line comment starts with #; a multi-line comment can be written with # on every line or inside triple quotes.

Example:
```python
# Program to find the area of a circle   (single-line comment)
r = 5
area = 3.14 * r * r     # formula: pi * r * r
"""
This is a multi-line comment
written using triple quotes.
"""
print("Area =", area)
```

Output:
```text
Area = 78.5
```

A constant is a value that does not change while the program runs.
- Literal constants are fixed values written directly in the program, such as 10, 3.14, "Hello", True.
- Python has no special keyword for named constants. By convention, a variable written in CAPITAL letters is treated as a constant and should not be changed, for example PI = 3.14159 and MAX_MARKS = 100.

```python
PI = 3.14159
MAX_MARKS = 100
print(PI, MAX_MARKS)
```

Output:
```text
3.14159 100
```

=== Q8
Question: What is indentation?
KL: K1
CO: CO1
PO: PO1
PSO: PSO1
Asked: April 2024 Q2
Answer:
Indentation is the white space (spaces or tabs) at the beginning of a line. Python uses indentation to mark a block of code, instead of braces { } used in C or Java. All statements in the same block must have the same indentation (4 spaces is the standard). Wrong indentation gives an IndentationError.

```python
marks = 75
if marks >= 40:
    print("Pass")        # indented: inside the if block
    print("Well done")
print("End")             # not indented: outside the block
```

Output:
```text
Pass
Well done
End
```

=== Q11
Question: What is type conversion?
KL: K1
CO: CO1
PO: PO1
PSO: PSO1
Asked: November 2025 Q11
Answer:
Type conversion is changing a value from one data type to another.
1. Implicit conversion: Python converts automatically, for example int + float gives float (5 + 2.5 = 7.5).
2. Explicit conversion (type casting): the programmer converts using functions such as int(), float(), str(), bool(), list(), tuple().

```python
a = 5 + 2.5          # implicit: int -> float
b = int("25")        # explicit: str -> int
c = str(100)         # explicit: int -> str
print(a, b + 1, c + "!")
```

Output:
```text
7.5 26 100!
```

The input() function reads a line typed by the user from the keyboard. It always returns the value as a string, so int() or float() is used to convert numbers.
